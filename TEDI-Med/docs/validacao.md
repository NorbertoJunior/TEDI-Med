# Validação e boas práticas

Organizamos o código em pacotes de modelo, serviços e interface gráfica. Utilizamos encapsulamento, validação de entradas e separação de responsabilidades. Mantivemos a versão de terminal e a classe de testes para verificar a evolução do sistema.

A compilação com Java 17 e as seis verificações automatizadas foram executadas com sucesso (ver `../testes.txt`). As seis operações da interface foram verificadas durante a demonstração e os testes funcionais informados pelo grupo. As capturas em `evidencias/` registram a abertura, o cadastro e a listagem. A [apresentação em vídeo](https://youtu.be/f62n2dOkR38) complementa essas evidências.

Os dados das imagens são demonstrativos. Não realizamos testes formais de usabilidade com idosos. O sistema não possui alarmes nem persistência após o encerramento.

A publicação da versão final utiliza Git; o histórico do repositório documentará os commits efetivamente realizados.
